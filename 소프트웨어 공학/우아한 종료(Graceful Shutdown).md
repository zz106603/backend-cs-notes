## 우아한 종료 (Graceful Shutdown)

### 1. 개념
애플리케이션이 종료될 때, **하던 작업을 안전하게 마무리하고 리소스를 정리한 뒤 종료**하는 것을 의미
- 컴퓨터를 끌 때 전원 코드를 바로 뽑는 것(Hard Shutdown)이 아니라, '시스템 종료' 버튼을 눌러 실행 중인 프로그램을 정리하고 끄는 것과 같음

---

### 2. 왜 필요한가? (문제 상황 예시)
서버가 요청을 처리하는 도중에 강제로 종료되면 다음과 같은 심각한 문제가 발생할 수 있음

1.  **데이터 손실 및 불일치**: 결제 로직이 실행되던 중 서버가 꺼지면, 돈은 나갔는데 주문은 생성되지 않는 데이터 정합성 문제가 발생할 수 있음
2.  **사용자 경험 저하**: 사용자는 영문도 모른 채 "연결 끊김" 오류를 보게 됨
3.  **리소스 누수**: 데이터베이스 커넥션이나 파일 핸들이 정상적으로 닫히지 않아, DB 서버에 유령 커넥션이 남을 수 있음

---

### 3. 동작 원리 (프로세스 시그널)
운영체제(OS)는 프로세스를 종료할 때 시그널(Signal)을 보냄

1.  **SIGTERM (Signal Terminate, 15)**:
    - 이제 종료할 거니까 정리하라는 **부드러운 종료 요청**
    - 애플리케이션은 이 신호를 감지(Catch)하여 종료 로직을 수행할 수 있음 (Graceful Shutdown의 핵심)
2.  **SIGKILL (Signal Kill, 9)**:
    - 지금 당장 끄라는 **강제 종료 명령**
    - 애플리케이션이 신호를 감지할 수 없으며, 즉시 프로세스가 소멸 (정리 작업 불가능)

> **실무 흐름**: 배포 시 `kill -15 (PID)` 명령을 보내거나, Kubernetes가 파드(Pod)를 삭제할 때 먼저 `SIGTERM`을 보내고 일정 시간(Grace Period)을 기다려줌. 그래도 안 꺼지면 `SIGKILL`을 보냄

---

### 4. Spring Boot에서의 적용 방법

스프링 부트 2.3 버전부터는 설정 파일(`application.yml` 또는 `properties`)만으로 간단하게 적용할 수 있음

```yaml
server:
  shutdown: graceful # 기본값은 immediate (즉시 종료)

spring:
  lifecycle:
    timeout-per-shutdown-phase: 30s # 최대 대기 시간 (기본 30초)
```

#### 동작 과정
1.  종료 신호(`SIGTERM`)가 들어옴
2.  스프링 부트는 **더 이상 새로운 요청을 받지 않도록 차단** (Load Balancer 등에서 제외되는 효과)
3.  이미 들어와서 **처리 중인 요청이 완료될 때까지 기다림**
4.  설정된 시간(`30s`) 내에 처리가 끝나면 정상 종료
5.  시간이 지나도 끝나지 않으면 강제로 종료

### 5. 실무 고려 사항 (Best Practice)

#### 1) 타임아웃 설정 (Timeout)
- 처리 중인 작업이 무한 루프에 빠지거나 데드락이 걸리면 서버가 영원히 안 꺼질 수 있음
- 따라서 반드시 적절한 **타임아웃(Timeout)** 을 설정해야 함 (보통 30초~60초 권장)

#### 2) 외부 리소스 정리
- 단순히 요청 처리만 기다리는 것이 아니라, 스케줄러(Scheduler)나 메시지 컨슈머(Kafka Consumer) 등도 안전하게 종료해야 함
- `@PreDestroy` 어노테이션을 사용하여 빈(Bean)이 소멸되기 전에 리소스 정리 로직을 작성할 수 있음

```java
@Component
public class ResourceCleaner {

    @PreDestroy
    public void cleanUp() {
        System.out.println("애플리케이션 종료 전 리소스를 정리합니다...");
        // 예: 열려있는 파일 닫기, 캐시 플러시, 알림 발송 등
    }
}
```

#### 3) 쿠버네티스(Kubernetes) 환경
- 쿠버네티스의 `terminationGracePeriodSeconds` 옵션과 스프링 부트의 타임아웃 시간을 맞춰야 함
- 보통 **K8s 대기 시간 > 스프링 부트 타임아웃**으로 설정하여, 스프링이 먼저 안전하게 종료될 수 있도록 여유를 줌
