## 전략 패턴 (Strategy Pattern)

### 1. 정의
- **객체의 행위(알고리즘)를 클래스로 캡슐화**하여, 동적으로 행위를 자유롭게 바꿀 수 있게 해주는 디자인 패턴
- 즉, 어떤 일을 수행하는 방식(전략)이 여러 가지일 때, 이를 추상화된 인터페이스로 정의하고 상황에 따라 적절한 구현체(전략)를 갈아끼워 사용하는 방식
- **핵심**: "변하는 부분(행위)"과 "변하지 않는 부분(컨텍스트)"을 분리하는 것

### 2. 왜 사용하는가? (장점)
- **유연성 및 확장성**: 새로운 전략(알고리즘)을 추가하더라도 기존 코드를 수정할 필요가 없음 (OCP - 개방 폐쇄 원칙 준수)
- **코드 재사용성**: 동일한 전략을 여러 객체에서 공유하여 사용할 수 있음
- **유지보수 용이**: 로직이 독립된 클래스로 분리되어 있어, 특정 전략만 수정하거나 테스트하기 쉬움

---

### 3. 구조 및 예시 코드

#### 상황 설정
자동차(`Car`)가 움직이는 조건이 상황에 따라 달라진다고 가정
1. 짝수일 때만 이동
2. 홀수일 때만 이동
3. 소수일 때만 이동

이때 `Car` 클래스의 코드를 매번 수정하는 대신, **이동 조건(전략)** 만 바꿔 끼울 수 있도록 설계

```java
// 1. 전략 인터페이스 (Strategy)
// 변하는 부분: 움직일 수 있는지 판단하는 알고리즘을 추상화
interface MoveStrategy {
    boolean isMovable(int input);
}

// 2. 구체적인 전략 구현체들 (Concrete Strategies)
// 짝수일 때만 이동하는 전략
class EvenNumberMoveStrategy implements MoveStrategy {
    @Override
    public boolean isMovable(int input) {
        return (input % 2) == 0;
    }
}

// 홀수일 때만 이동하는 전략
class OddNumberMoveStrategy implements MoveStrategy {
    @Override
    public boolean isMovable(int input) {
        return (input % 2) != 0;
    }
}

// 3. 컨텍스트 (Context)
// 변하지 않는 부분: 자동차의 상태와 이동한다는 행위 자체
class Car {
    private final MoveStrategy strategy; // 전략을 가짐 (Composition)
    private final int position;

    // 생성자를 통해 구체적인 전략을 주입받음 (DI)
    public Car(MoveStrategy strategy, int position) {
        this.strategy = strategy;
        this.position = position;
    }

    public void move(int input) {
        // 구체적인 판단 로직은 전략 객체에게 위임
        if (strategy.isMovable(input)) {
            // 위치 이동 로직 (예시)
            System.out.println("자동차가 이동합니다.");
        } else {
            System.out.println("자동차가 멈춰있습니다.");
        }
    }
}

// 4. 클라이언트 (Client)
public class Main {
    public static void main(String[] args) {
        // 짝수 전략을 사용하는 자동차 생성
        Car evenCar = new Car(new EvenNumberMoveStrategy(), 0);
        evenCar.move(2); // 이동함
        evenCar.move(3); // 멈춤

        // 홀수 전략을 사용하는 자동차 생성
        Car oddCar = new Car(new OddNumberMoveStrategy(), 0);
        oddCar.move(2); // 멈춤
        oddCar.move(3); // 이동함
    }
}
```

### 4. 요약
- **Strategy (전략)**: `MoveStrategy` 인터페이스. 알고리즘군을 정의
- **ConcreteStrategy (구체적 전략)**: `EvenNumberMoveStrategy`, `OddNumberMoveStrategy` 실제 알고리즘을 구현
- **Context (문맥)**: `Car` 클래스. 전략을 사용하여 기능을 수행합니다. 전략이 바뀌어도 `Car`의 코드는 변하지 않음

### 5. 실무 활용 예시
- **결제 방식**: 신용카드, 카카오페이, 네이버페이 등 결제 수단에 따라 다른 결제 로직 수행
- **할인 정책**: 고정 금액 할인, 퍼센트 할인 등 정책에 따라 다른 가격 계산 로직 수행
- **정렬 알고리즘**: 퀵 정렬, 병합 정렬 등 상황에 따라 다른 정렬 방식 선택
