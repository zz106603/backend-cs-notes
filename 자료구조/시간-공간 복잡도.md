### 시간 복잡도와 공간 복잡도 (Time & Space Complexity)

**정의**

- **시간 복잡도 (Time Complexity):** 알고리즘이 문제를 해결하는 데 걸리는 시간(연산 횟수)이 입력 크기(N)에 따라 어떻게 증가하는지를 나타냄
- **공간 복잡도 (Space Complexity):** 알고리즘 실행 시 필요한 메모리 공간의 양이 입력 크기(N)에 따라 어떻게 변하는지를 나타냄
- **핵심:** "정확한 시간(초)"이나 "정확한 메모리(MB)"를 재는 것이 아니라, **"입력(N)이 늘어날 때 얼마나 비효율적으로 변하는가?"** 를 따지는 척도

---

### 빅오 표기법 (Big-O Notation)

가장 최악의 경우(Worst Case)를 상정하여 복잡도를 표현하는 방법. 상수항이나 계수는 무시하고, **가장 큰 영향력을 가진 항**만 표기

#### 주요 시간 복잡도 종류 (빠른 순서대로)

1.  **O(1) - 상수 시간 (Constant Time)**
    - 입력 크기(N)와 상관없이 항상 일정한 시간이 걸림
    - **예시:** 배열의 인덱스로 접근하기 (`arr[5]`), 스택의 `push`/`pop`
    ```java
    int getFirst(int[] arr) {
        return arr[0]; // N이 100만이든 1억이든 한 번에 끝남
    }
    ```

2.  **O(log N) - 로그 시간 (Logarithmic Time)**
    - 입력 크기가 커질수록 처리 시간이 아주 조금씩 늘어남 (매우 효율적)
    - **예시:** **이진 탐색 (Binary Search)**
    ```java
    // 100개의 데이터 -> 7번만 찾으면 됨
    // 100만개의 데이터 -> 20번만 찾으면 됨
    ```

3.  **O(N) - 선형 시간 (Linear Time)**
    - 입력 크기에 비례해서 시간이 걸림
    - **예시:** `for` 문 하나, 배열 전체 탐색
    ```java
    for (int i = 0; i < n; i++) {
        System.out.println(i);
    }
    ```

4.  **O(N log N) - 선형 로그 시간**
    - **예시:** 효율적인 정렬 알고리즘 (**Merge Sort, Quick Sort, Heap Sort**)
    - 일반적인 정렬(`Arrays.sort()`)은 보통 이 복잡도를 가짐


5.  **O(N^2) - 이차 시간 (Quadratic Time)**
    - 입력 크기의 제곱만큼 시간이 걸림. N이 조금만 커져도 매우 느려짐
    - **예시:** **이중 for 문**, 버블 정렬, 삽입 정렬
    ```java
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            // ...
        }
    }
    ```

6.  **O(2^N) - 지수 시간 (Exponential Time)**
    - **예시:** 피보나치 수열 재귀 (메모이제이션 없이), 외판원 순회 문제
    - N이 100만 되어도 계산이 불가능할 정도로 느림

### 복잡도 구하는 꿀팁 (실전용)

**1. 반복문(Loop)을 찾아라**
- `for` 문이 하나면 **O(N)**
- `for` 문 안에 `for` 문이 있으면(중첩) **O(N^2)**
- `for` 문이 두 개 따로 있으면 O(N + N) = **O(N)** (큰 것만 남김)

**2. 입력 크기(N)를 보고 알고리즘을 선택 (코딩테스트 팁)**
- **N ≤ 1,000,000 (100만):** O(N) 또는 O(N log N) 알고리즘을 써야 함
- **N ≤ 10,000 (1만):** O(N^2)도 통과 가능
- **N ≤ 500:** O(N^3)도 가능
- **N이 매우 큼 (10억 이상):** O(log N) 또는 O(1)이어야 함

**3. 공간 복잡도는 변수를 봐라**
- `int a[N]` 배열을 선언했다 -> **O(N)**
- `int a[N][N]` 2차원 배열이다 -> **O(N^2)**
- 그냥 변수 `int i, k` 몇 개만 쓴다 -> **O(1)** (입력 크기와 무관하므로)

### 예시 코드로 보는 복잡도 계산

```java
// 예제 1: O(N)
// N번 반복하므로
void func1(int n) {
    for (int i = 0; i < n; i++) { ... }
}

// 예제 2: O(N^2)
// 바깥 N번 * 안쪽 N번 = N^2
void func2(int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) { ... }
    }
}

// 예제 3: O(log N)
// i가 2배씩 커지므로 반복 횟수가 확 줄어듦 (1, 2, 4, 8, 16...)
void func3(int n) {
    for (int i = 1; i < n; i *= 2) { ... }
}
```
