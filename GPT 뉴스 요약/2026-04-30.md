## 뉴스 1
### OpenAI, 기업용 AI 에이전트 자동화 기능 강화 발표
- **핵심 요약**
  - OpenAI가 API 기반 에이전트 기능을 강화하여, 여러 단계 작업을 자동으로 수행하는 워크플로우 지원 확대
  - 외부 툴 호출 및 상태 유지 기능 개선
- **중요 이유**
  - 단순 LLM 호출에서 "자동화된 작업 수행 시스템"으로 진화
  - SaaS, 내부툴, 백오피스 자동화 구조 자체가 바뀌는 흐름
- **백엔드 관점 포인트**
  - AI를 단일 API 호출이 아닌 "상태 있는 시스템"으로 설계 필요
  - Tool calling / function orchestration 구조 중요
  - queue + worker + AI agent 구조 패턴 확산
- **링크**
  - https://openai.com

## 뉴스 2
### Google, GCP에서 AI 추론 최적화 인프라 업데이트 발표
- **핵심 요약**
  - Google Cloud가 AI 추론 성능 개선을 위한 TPU 및 GPU 자동 스케일링 기능을 강화
  - latency 최적화 및 비용 효율성 강조
- **중요 이유**
  - AI 서비스의 핵심은 "추론 비용 + 속도"
  - 이 부분 개선은 AI 제품의 수익성과 직결됨
- **백엔드 관점 포인트**
  - inference workload를 고려한 아키텍처 설계 필요
  - autoscaling + request batching 전략 중요
  - GPU 자원 관리가 핵심 백엔드 역량으로 부상
- **링크**
  - https://cloud.google.com

## 뉴스 3
### Amazon Web Services, 컨테이너 기반 서버리스(ECS/Fargate) 기능 확장
- **핵심 요약**
  - AWS가 ECS 및 Fargate에서 더 빠른 스케일링과 네트워크 성능 개선을 발표
  - 컨테이너 기반 서버리스 활용성 증가
- **중요 이유**
  - 서버리스 vs 컨테이너 경계가 점점 사라지는 중
  - 운영 부담 없이 고성능 백엔드 구성 가능
- **백엔드 관점 포인트**
  - Lambda 한계를 넘는 서버리스 아키텍처 선택지 증가
  - microservice + container 기반 설계 유리
  - CI/CD + 이미지 빌드 최적화 중요성 증가
- **링크**
  - https://aws.amazon.com

### Meta, LLM 경량화 및 온디바이스 AI 실행 기술 공개
- **핵심 요약**
  - Meta가 소형 LLM을 모바일 및 엣지 환경에서 실행할 수 있는 최적화 기술 공개
  - latency 감소 및 개인정보 보호 강조
- **중요 이유**
  - 클라우드 중심 AI -> 온디바이스 AI로 확장
  - 아키텍처 패러다임 변화 시작
- **백엔드 관점 포인트**

  - API 중심 구조 -> hybrid 구조 (client + server AI) 변화
  - 데이터 처리 위치 설계(서버 vs 클라이언트) 중요
- **링크**
  - https://ai.meta.com
