# Backend CS Notes

백엔드 개발자를 위한 컴퓨터 공학(CS) 및 소프트웨어 공학 지식 정리 저장소입니다.
학습한 내용을 주제별로 분류하여 정리하고 있습니다.

## 📂 목차 (Categories)

각 주제를 클릭하면 해당 디렉토리로 이동하여 상세 문서를 확인할 수 있습니다.

### [🏗️ 소프트웨어 공학 (Software Engineering)](./소프트웨어%20공학)
- 디자인 패턴 (전략 패턴, CQRS 등)
- 아키텍처 및 배포 전략 (무중단 배포, CI/CD, SPOF)
- 테스트 방법론 (TDD, 테스트 더블)

### [🌸 Spring](./Spring)
- 스프링 프레임워크 핵심 원리 (DI)
- 스프링 트랜잭션 (전파 속성, AOP 동작 흐름)
- JPA (Lazy Loading, OneToOne 관계 Lazy Loading)

### [🌐 네트워크 (Network)](./네트워크)
- 네트워크 프로토콜 및 통신 (DNS, IP 주소 체계, 교환 방식, Keep-Alive)
- 네트워크 장비 및 기술 (NAT, CDN)

### [💾 데이터베이스 (Database)](./데이터베이스)
- 데이터 모델링 (정규화)
- 분산 락 및 동시성 제어 (Redis 분산 락)

### [💻 운영체제 (Operating System)](./운영체제)
- 커널 및 시스템 (시스템 콜, 우아한 종료, 프로세스 시스템)
- 메모리 관리 (연속 메모리 할당)
- 동시성 제어 (경쟁 상태 해결, 멀티 태스킹의 한계)

### [🛡️ 보안 (Security)](./보안)
- 웹 보안 취약점 및 방어 (CSRF 공격)
- 암호학 및 인증 (암호화 방식, JWT)

### [⌨️ 프로그래밍 (Programming)](./프로그래밍)
- 프로그래밍 패러다임 (함수형 프로그래밍)
- 언어별 심화 지식 (Java 클래스 정보/리플렉션, String 객체, Thread-Safe, String 변환, 제네릭, JCF 초기 용량 설정)

### [🧱 자료구조 (Data Structure)](./자료구조)
- 데이터 구조 및 알고리즘 (연결 리스트, 트라이, 시간-공간 복잡도)

### [🤖 AI](./AI)
- LLM 연동 (MCP, RAG)

### [🐧 DevOps](./DevOps)
- 인프라 관리 (IaC)
