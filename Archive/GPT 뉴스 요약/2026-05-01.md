## 뉴스 1
### Microsoft, Azure에서 AI 에이전트 오케스트레이션 기능 공개
- **핵심 요약**
  - Microsoft가 Azure AI 플랫폼에서 여러 AI 모델과 외부 툴을 연결해 작업을 자동 수행하는 “에이전트 오케스트레이션” 기능을 발표
  - 상태 관리 및 워크플로우 실행 기능 포함
- **중요 이유**
  - 단순 LLM 호출을 넘어 “AI 기반 백엔드 시스템” 구축이 표준으로 변화
  - SaaS 및 내부 시스템 구조 자체가 재편되는 흐름
- **백엔드 관점 포인트**
  - AI를 stateless API가 아닌 stateful workflow로 설계 필요
  - orchestration layer (queue, state store, scheduler) 중요
  - 기존 BPM/워크플로우 엔진과 AI 결합 트렌드
- **링크**
  - https://azure.microsoft.com

## 뉴스 2
### Amazon Web Services, Aurora Serverless v2 확장 및 성능 개선 발표
- **핵심 요약**
  - AWS가 Aurora Serverless v2에서 더 빠른 scaling과 읽기/쓰기 처리량 개선을 발표
  - 트랜잭션 처리 성능과 안정성 강화
- **중요 이유**
  - 서버리스 DB의 가장 큰 약점이었던 latency와 scaling 문제 개선 → 실서비스 적용 가능성 확대
- **백엔드 관점 포인트**
  - RDS → Serverless DB 전환 검토 가능
  - onnection pooling 전략 변화 필요 (cold scaling 고려)
  - 비용 최적화 + autoscaling DB 설계 중요
- **링크**
  - https://aws.amazon.com/rds/aurora/

## 뉴스 3
### Google, Kubernetes Autopilot 모드 기능 강화
- **핵심 요약**
  - GCP에서 Kubernetes Autopilot의 리소스 자동 관리 및 보안 정책 기능이 개선됨
  - 운영 부담 없이 컨테이너 워크로드 관리 가능
- **중요 이유**
  - Kubernetes의 복잡성을 줄이고 “관리형 인프라”로 진화
  - DevOps 비용 절감과 생산성 향상
- **백엔드 관점 포인트**
  - 인프라 운영 → 플랫폼 의존 구조로 변화
  - 리소스 최적화 및 비용 관리 자동화
  - DevOps 엔지니어 역할이 “설계 중심”으로 이동
- **링크**
  - https://cloud.google.com/kubernetes-engine

## 뉴스 4
### Meta, LLM 추론 최적화 라이브러리 공개
- **핵심 요약**
  - Meta가 대규모 언어 모델의 추론 속도와 비용을 줄이기 위한 최적화 라이브러리를 오픈소스로 공개
  - batching 및 메모리 효율 개선 포함
- **중요 이유**
  - AI 서비스의 핵심은 “추론 비용”
  - 이 최적화는 서비스 수익성과 직결되는 요소
- **백엔드 관점 포인트**
  - inference server 최적화 (batching, caching) 중요
  - GPU utilization 극대화 필요
  - AI도 결국 “성능 엔지니어링 문제”로 귀결
- **링크**
  - https://ai.meta.com
