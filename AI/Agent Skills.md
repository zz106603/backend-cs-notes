# Agent Skills

## Agent Skills

AI 에이전트가 특정 작업을 수행할 때 필요한 **지침, 작업 절차, 참고 자료, 실행 스크립트 등을 재사용할 수 있도록 정의한 기능**

Codex나 Claude Code 같은 AI 에이전트는 사용자의 프롬프트를 해석해 작업을 수행. 하지만 코드 리뷰, 테스트 작성, 아키텍처 검토와 같이 반복되는 작업에서는 매번 동일한 지침을 전달해야 하는 불편함이 있음

Agent Skills는 이러한 작업 방식을 미리 정의하여 AI가 필요한 시점에 해당 지침을 불러와 사용

### 핵심 목적
- 반복되는 작업 절차를 표준화하고 재사용
- 프롬프트마다 동일한 지침을 작성하는 불편함 감소
- 작업별 검증 항목과 결과 형식의 일관성 확보
- 필요할 때만 관련 지침을 불러와 컨텍스트 사용량 관리

즉, 일반적인 프롬프트가 AI에게 **무엇을 할지 요청하는 것**이라면 Skill은 특정 작업을 **어떤 절차와 기준으로 수행할지 정의하는 것**

## 필요 이유

### 일반적인 프롬프트 방식
```
현재 작성한 코드를 검토해 줘.

트랜잭션, 동시성, N+1, 예외 처리 문제를 확인하고
문제가 있다면 원인과 개선 방법을 설명해 줘.
```

- 반복적으로 코드 리뷰를 요청할 경우 매번 검토 항목을 작성해야 함
- 프롬프트에 따라 검토 기준이 달라지거나 중요한 항목이 누락될 가능성이 있음

### Skill 사용 방식
```
$code-review 현재 변경한 코드를 검토해 줘.
```

- Skill에 정의된 절차를 참고하여 변경 사항 분석, 잠재적 오류 검토, 테스트 확인 등의 작업을 수행

**차이점은 검토 절차를 매번 대화에서 지정하는지, 별도의 파일로 관리하여 재사용하는지**

## Agent Skills의 구성
Agent Skills는 `SKILL.md` 파일을 중심으로 구성됨

Skill의 이름, 설명, 작업 절차를 정의하며 필요에 따라 참고 문서와 스크립트를 추가할 수 있음

### 기본 디렉터리 구조
```
code-review/
├── SKILL.md
├── references/
│   └── review-guidelines.md
├── scripts/
│   └── run-tests.sh
└── assets/
    └── review-template.md
```

| 구성 요소 | 역할 |
| --- | --- |
| `SKILL.md` | Skill의 이름, 실행 조건, 작업 절차 정의 |
| `references/` | 작업에 필요한 상세 가이드 및 참고 문서 |
| `scripts/` | 테스트나 검증 등 반복 실행할 스크립트 |
| `assets/` | 보고서 양식 등 재사용할 템플릿 |

### SKILL.md 작성 예시
```markdown
---
name: code-review
description: 코드 변경 사항에 대한 버그, 성능,
  트랜잭션 및 동시성 문제를 검토할 때 사용한다.
---

# Code Review

## 작업 절차

1. 변경된 코드와 관련 호출 흐름을 확인한다.
2. 비즈니스 로직 및 예외 처리 문제를 검토한다.
3. 트랜잭션과 동시성 문제를 검토한다.
4. N+1 및 불필요한 DB 조회를 확인한다.
5. 필요한 테스트가 존재하는지 확인한다.

## 결과 작성

- 발견한 문제를 심각도 순으로 정리한다.
- 문제 발생 조건과 근거를 제시한다.
- 개선 방법과 대안을 설명한다.
- 검증하지 못한 부분은 별도로 명시한다.
```

- 파일 상단의 `---`로 구분된 영역은 **YAML Front Matter**라고 하며 Skill의 메타데이터를 정의
- `name`은 Skill의 식별 이름이고 `description`은 Skill을 어떤 상황에서 사용해야 하는지 판단하기 위한 설명
- 이후 Markdown 본문에는 작업 순서와 결과 형식 등을 작성

## Agent Skills의 동작 방식

### 동작 흐름
```
사용자 요청
    ↓
사용 가능한 Skill 탐색
    ↓
name / description 확인
    ↓
관련 Skill 선택
    ↓
SKILL.md 지침 불러오기
    ↓
필요한 참고 문서 및 스크립트 활용
    ↓
작업 수행 및 결과 제공
```

### Skill 호출 방식

#### 1. 명시적 호출
사용자가 사용할 Skill을 지정하는 방식
```
$code-review 좋아요 기능을 검토해 줘.
```

#### 2. 자동 선택
사용자가 Skill을 명시하지 않더라도 요청 내용이 Skill의 설명과 관련되어 있다면 Codex가 해당 Skill을 선택
```
이번에 구현한 좋아요 기능에서
동시성 문제가 발생할 수 있는지 확인해 줘.
```

- 자동 선택은 항상 보장되는 것이 아니므로 중요한 작업에서는 명시적으로 호출하는 것이 좋음

### Progressive Disclosure (점진적 정보 제공)

Agent Skills는 모든 지침을 처음부터 불러오지 않고 필요한 정보만 단계적으로 읽는 방식을 사용

처음에는 Skill의 이름과 설명을 통해 사용 가능 여부를 판단하고, Skill이 선택되면 `SKILL.md`의 상세 내용을 불러옴. 추가 문서나 스크립트 역시 필요한 시점에 활용

이 구조는 여러 Skill이 존재하더라도 모든 작업 지침을 항상 컨텍스트에 포함하지 않도록하여 불필요한 토큰 사용을 줄이는 데 도움이 됨

## AGENTS.md와 Skills의 차이
Codex에서는 `AGENTS.md`와 Skills를 함께 사용

| 구분 | AGENTS.md | AgentSkills |
| --- | --- | --- |
| 목적 | 프로젝트의 공통 지침 정의 | 특정 작업의 절차 정의 |
| 적용 시점 | 해당 범위에서 작업할 때 기본 적용 | 관련 작업이 발생했을 때 선택 |
| 내용 | 기술 스택, 구조, 개발 규칙 | 코드 리뷰, 테스트, 배포 절차 |
| 관리 방식 | 프로젝트 지침 파일 | 작업별 Skill 디렉터리 |

### AGENTS.md의 역할
- 프로젝트 전체에서 공통적으로 적용할 규칙을 작성
- Java 17, 패키지 구조 유지, Flyway 기반 스키마 관리, 기존 API 호환성 유지 등 지침

### Skills의 역할
- 코드 리뷰, 테스트 생성, 성능 분석 등 특정 작업에 필요한 절차를 정의
- 코드 리뷰 Skill이라면 변경된 코드 분석부터 잠재적 오류 확인, 테스트 실행, 리뷰 결과 작성까지의 흐름 정의

> AGNETS.md는 프로젝트에서 지켜야 할 공통 규칙이고 Skill은 특정 작업을 수행하는 방법

## 백엔드 개발에서의 활용 사례

| Skill | 활용 목적 |
| --- | --- |
| `code-review` | 버그, 예외 처리, 트랜잭션, 동시성 검토 |
| `test-generator` | 정상/예외/경계 조건에 대한 테스트 작성 |
| `api-review` | REST API 설계, 응답 구조, 오류 코드 검토 |
| `performence-review` | N+1, 인덱스, 쿼리 및 성능 문제 분석 |
| `architecture-review` | 설계 대안과 장단점 비교 |
| `pr-review` | 변경 사항과 테스트 결과를 바탕으로 PR 검토 |

- 좋아요 기능을 개발했다면 `code-review` Skill로 데이터 정합성과 동시성 문제를 검토하고 `test-generator` Skill로 중복 요청이나 동시 요청에 대한 테스트를 작성
- 이처럼 Skill은 **기존에 AI가 수행하던 작업을 일관된 절차로 관리하는 방법**

## Skills 사용 시 중의사항

### Skill은 정확성을 보장하지 않음
Skill에 검토 기준을 자세히 작성하더라도 AI가 모든 문제를 발견하는 것은 아님

특히 동시성, 트랜잭션, 성능 관련 문제는 실제 실행 환경이나 테스트 결과를 통해 검증해야 함

### 모든 작업을 Skill로 만들 필요는 없음
단순한 질문이나 일회성 작업은 일반적인 프롬프트로 처리해도 충분함

Skill은 반복되는 작업이 존재하고 수행 절차를 표준화할 필요가 있을 때 효과적임. 따라서 자주 사용되는 작업부터 작은 단위로 만들어 점차 개선하는 것이 좋음

### 지침이 많다고 좋은 것은 아님
`AGENTS.md`와 Skill에 불필요한 지침을 많이 작성하면 작업에 필요한 정보보다 규칙이 많아져 오히려 AI의 판단을 제한하거나 지침 충돌이 발생할 수 있음

공통 규칙은 `AGENTS.md`에 간결하게 정의하고 특정 작업의 상세 절차는 SKill로 분리하는 것이 좋음

## 핵심 정리
Agent Skills는 AI 에이전트가 반복적으로 수행하는 작업의 절차와 기준을 정의하고 재사용하기 위한 기능

- Skill은 `SKILL.md`를 중심으로 구성
- 필요에 따라 참고 문서, 스크립트, 템플릿을 포함
- AI 에이전트는 사용자 요청과 Skill의 설명을 바탕으로 관련 Skill을 선택하고 정의된 절차를 활용하여 작업을 수행

### 주요 개념 구분
- **Prompt**: AI에게 수행할 작업을 요청
- **AGENTS.md**: 프로젝트의 공통 작업 규칙 정의
- **Agent SKills**: 특정 작업의 수행 절차를 정의하고 재사용

Skill의 핵심 가치는 AI의 능력을 새롭게 추가하는 것보다 반복되는 작업을 체계적으로 관리하고 결과의 일관성을 높이는 데 있음
