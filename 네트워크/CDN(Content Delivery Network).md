### CDN (Content Delivery Network)

**정의**
- 지리적으로 분산된 서버들을 연결하여, 사용자가 웹 콘텐츠(이미지, 동영상, HTML 등)를 더 빠르고 안정적으로 다운로드할 수 있게 해주는 시스템
- **비유:** **"해외 직구 vs 쿠팡 로켓배송"**
    - **원본 서버(미국 쇼핑몰):** 물건 하나 사려면 배송이 2주 걸림 (거리 멀음, 속도 느림)
    - **CDN 서버(동네 물류센터):** 미리 물건을 갖다 놓아서 주문하면 다음 날 도착함 (거리 가까움, 속도 빠름)

**사용 이유 (장점)**
1.  **로딩 속도 개선:** 사용자와 가장 가까운 서버(Edge Server)에서 콘텐츠를 전송하므로 지연 시간(Latency)이 획기적으로 줄어듬
2.  **서버 부하 분산:** 트래픽이 CDN으로 분산되므로 원본 서버(Origin Server)의 부하가 줄어듬
3.  **보안 강화:** DDoS 공격 등을 CDN이 1차적으로 막아주어 원본 서버를 보호

---

### CDN 동작 방식 (흐름)

사용자가 `www.example.com/image.jpg`를 요청했을 때의 과정

1.  **사용자 요청:** 사용자가 브라우저에 URL을 입력
2.  **DNS 조회:** DNS 서버가 사용자의 위치에서 가장 가까운 **CDN 엣지 서버(Edge Server)** 의 IP 주소를 알려줌
3.  **캐시 확인 (Cache Hit/Miss):**
    - **Cache Hit:** 엣지 서버에 이미 `image.jpg`가 있다면, **즉시 사용자에게 반환** (여기서 끝)
    - **Cache Miss:** 엣지 서버에 파일이 없다면, **원본 서버(Origin Server)** 에 요청하여 파일을 받아옴
4.  **응답 및 저장:** 원본 서버로부터 받은 파일을 사용자에게 전달하고, 동시에 **자신의 캐시에 저장**해둠 (다음 요청부터는 바로 줄 수 있도록)

### 캐싱 방식 (Push vs Pull)

실무에서는 주로 **Pull 방식**을 기본으로 사용하고, 중요한 파일만 **Push**를 섞어 사용

#### 1. Pull 방식 (Reactive)
- **동작:** 사용자가 요청할 때, CDN에 없으면 그때서야 원본 서버에서 가져옴
- **장점:** 설정이 간편하고, 실제로 요청되는 데이터만 캐싱하므로 공간 효율이 좋음
- **단점:** **최초 요청(First Request)** 은 원본 서버를 다녀와야 하므로 속도가 느림
- **실무 예시:** 일반적인 쇼핑몰 상품 이미지, 블로그 게시글 이미지

#### 2. Push 방식 (Proactive)
- **동작:** 관리자가 미리 원본 서버의 콘텐츠를 CDN 서버에 강제로 업로드(배포)
- **장점:** 최초 요청부터 빠른 속도를 보장
- **단점:** 매번 수동으로 배포해야 하거나 별도 파이프라인이 필요하며, 안 쓰이는 데이터도 공간을 차지함
- **실무 예시:** 대규모 게임 패치 파일, 이벤트 오픈 시 트래픽 폭주가 예상되는 메인 배너 이미지

### 실무 고려사항

CDN을 도입할 때 개발자가 반드시 신경 써야 할 포인트

**1. 캐시 만료 시간 (TTL, Time To Live)**
- **문제:** TTL을 너무 길게 잡으면, 원본 이미지를 수정했는데도 사용자는 며칠 동안 옛날 이미지를 보게 됨. 반대로 너무 짧으면 원본 서버 부하가 줄어들지 않음
- **해결:** 적절한 TTL 설정이 중요함 (보통 정적 자원은 1일~1주일, 동적 자원은 짧게)

**2. 캐시 무효화 (Cache Invalidation)**
- **상황:** 긴급하게 배포된 CSS 파일에 버그가 있어서 수정. 하지만 CDN 캐시 때문에 사용자는 여전히 버그가 있는 CSS를 로드함
- **해결:**
    - **Purge (퍼지):** CDN 관리 콘솔에서 강제로 캐시를 삭제 (전파되는 데 시간이 좀 걸릴 수 있음)
    - **Versioning (버저닝):** 파일명 뒤에 버전을 붙여서 아예 새로운 파일로 인식하게 합니다. (가장 확실한 방법)
        - 예: `style.css?v=1.2` 또는 `style.v1.2.css`

**3. 비용 관리**
- CDN은 공짜가 아니라 전송량(Traffic)에 따라 과금
- 불필요하게 큰 이미지나 동영상을 캐싱하지 않도록 주의해야 함 (이미지 최적화/압축 필수)
