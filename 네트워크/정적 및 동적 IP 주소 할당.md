## 정적 & 동적 IP 할당 방식
네트워크에서 호스트(PC, 서버 등)에게 IP 주소를 부여하는 두 가지 주요 방식에 대한 정리

---

### 1. 정적 할당 (Static Allocation)
관리자가 호스트에 IP 주소를 **수동으로 직접 설정**하는 방식

- **설정 요소**: IP 주소, 서브넷 마스크, 게이트웨이, DNS 주소 등
- **장점**:
  - IP 주소가 변하지 않아 서버 운영이나 원격 접속 관리에 유리함
  - 문제 발생 시 트러블슈팅이 비교적 명확함
- **단점**:
  - 호스트 수가 많아지면 일일이 설정하기 번거로움 (관리 비용 증가)
  - IP 주소 중복 입력 등 휴먼 에러 발생 가능성 있음
- **주 사용처**: 서버, 네트워크 장비, 프린터 등 고정된 주소가 필요한 장비

### 2. 동적 할당 (Dynamic Allocation)
호스트가 네트워크에 접속할 때 **자동으로 IP 주소를 할당**받는 방식

- **주요 프로토콜**: **DHCP** (Dynamic Host Configuration Protocol)
  - IPv4: DHCPv4
  - IPv6: DHCPv6
- **특징**:
  - DHCP 서버가 사용 가능한 IP 풀(Pool)에서 사용하지 않는 IP를 호스트에게 **임대(Lease)** 해줌
  - 임대 기간이 끝나거나 재접속 시 IP 주소가 변경될 수 있음
- **장점**:
  - IP 관리 자동화로 관리자 편의성 증대
  - IP 충돌 방지 및 효율적인 IP 자원 활용 가능
- **주 사용처**: 일반 사용자 PC, 스마트폰, 노트북 등 이동이 잦거나 수가 많은 단말

---

### DHCP를 이용한 IP 할당 과정 (DORA Process)
DHCP 할당은 호스트와 DHCP 서버(주로 라우터나 전용 서버) 간의 4단계 통신으로 이루어짐

1.  **Discover (탐색)**
    - **주체**: 호스트 (Client) -> DHCP 서버 (Broadcast)
    - **내용**: "DHCP 서버 있나요? IP 주소 좀 주세요."
    - 호스트가 네트워크에 브로드캐스트 메시지를 보내 DHCP 서버를 찾음

2.  **Offer (제안)**
    - **주체**: DHCP 서버 -> 호스트
    - **내용**: "여기 192.168.0.10 쓸 수 있어요. 임대 기간은 24시간입니다."
    - DHCP 서버가 할당 가능한 IP 주소와 임대 기간 등의 정보를 담아 호스트에게 제안

3.  **Request (요청)**
    - **주체**: 호스트 -> DHCP 서버 (Broadcast)
    - **내용**: "네, 그 IP(192.168.0.10) 사용할게요."
    - 호스트가 제안받은 IP를 사용하겠다고 서버에 요청함 (여러 DHCP 서버가 있을 수 있으므로 브로드캐스트로 전송하여 다른 서버들도 알게 함)

4.  **Acknowledgment (승인)**
    - **주체**: DHCP 서버 -> 호스트
    - **내용**: "확인했습니다. 이제 그 IP 쓰세요."
    - 서버가 최종적으로 IP 임대를 승인하며, 호스트는 해당 IP를 네트워크 설정에 적용

> **참고**: 임대 기간이 만료되기 전에 호스트는 **DHCP 갱신(Renewal)** 요청을 보내 IP 사용 기간을 연장할 수 있음

### 요약 및 실무 활용

| 구분 | 개인/가정 환경 | 기업/서버 환경 |
| :--- | :--- | :--- |
| **DHCP 주체** | 공유기 (Router) | 전용 DHCP 서버 / L3 스위치 |
| **정적 IP 사용** | 테스트 목적, NAS 등 | 운영 서버, 보안 장비, 네트워크 인프라 |
| **동적 IP 사용** | PC, 스마트폰, IoT 기기 | 직원용 PC, 게스트 Wi-Fi |
| **장애 영향** | 내 PC만 인터넷 불가 | 전체 서비스 장애 가능성 |

#### 실무 Tip: DHCP Reservation (DHCP 예약)
- **개념**: DHCP를 사용하되, 특정 MAC 주소를 가진 장비에게는 **항상 동일한 IP 주소**를 할당하도록 설정하는 기능
- **장점**:
  - 클라이언트(PC, 프린터 등)에서 일일이 정적 IP를 설정할 필요가 없음 (설정 자동화)
  - 관리자는 중앙(DHCP 서버)에서 IP를 고정적으로 관리할 수 있어 편리함
  - IP가 바뀌면 안 되는 프린터나 내부 서버 등에 유용하게 사용됨
